# Lab 01: Introduction to Linux

## Objective
To understand basic Linux commands and become
comfortable navigating the Ubuntu terminal.

## Environment
- Operating System: Windows 11
- Linux Distribution: Ubuntu
- Virtualisation: WSL2

## Commands Practised

| Command | Purpose |
| whoami  | Displays current user |
| pwd     | Displays current directory (Print Working Directory)|
| ls      | Lists files and folders |
| mkdir   | Creates a directory |
| touch   | Creates an empty file |
| cat     | Displays file contents |
|cd ..    | Move a directory back|
|sudo apt update| updates ubuntu packages|

## Practical Activities

1. Opened the Ubuntu terminal.
2. Identified my Linux username.
3. Checked my current working directory.
4. Created a cybersecurity-labs directory.
5. Created a text file.
6. Wrote information into the file.
7. Displayed the file contents.
